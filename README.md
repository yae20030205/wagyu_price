# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？

- リモートリポジトリ:ネット上に配置された複数人で共有するためのファイルや変更履歴の保管場所
- ローカルリポジトリ:自分のPC上に配置されるファイルや変更履歴の保管場所

## プッシュとマージの違いは何でしょうか？

- プッシュ:ローカルリポジトリで変更した内容をリモートリポジトリに反映するコマンド
- マージ:同環境内で並行して存在する変更差分を反映させるコマンド

## コミットとプッシュの違い

- コミット:変更した内容をローカルリポジトリに保存するコマンド
- プッシュ:ローカルリポジトリでコミットした変更差分をリモートリポジトリに反映するコマンド

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？

- 変更内容が伝わりやすいよう簡潔に内容を記入する

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？

- ローカルでマージするフロー:  
派生したブランチでコミットしたものを幹ブランチにマージし、それをプッシュすることでリモートに反映する
- プルリクエストでマージするフロー:  
ローカル上の派生ブランチをプッシュし、リモート上の派生ブランチからプルリクエストを出し、レビュー、承認を得てからリモート上のmainブランチにマージする

## コンフリクトを起こしてしまった場合、どう対処すべきですか？

- 変更箇所を確認し、どの変更を取り込むかをコンクリフトを起こしてしまった相手と相談しながら判断する
